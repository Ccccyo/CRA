# D&B 评级与评分说明（公开资料）

> 来源：根据 Dun & Bradstreet 公开的 Rating Key、PAYDEX 和 Failure Score 说明整理（中文转述，非原文）。
> D&B 会调整区间和名称，正式使用前以 D&B 官网最新版本为准。
> 层级：公开资料，只作参考；CRA 里 D&B 评级怎么折算成分数，以公司《CRA 打分规则》为准。
> 演示中的 DUNS、Paydex、失败评分、评级都是编造的，不对应真实企业。

## D&B Rating 由两部分组成
一个评级如 **3A2**：前半部分「3A」是**估计财务实力**（Estimated Financial Strength），后半部分「2」是**综合信用评估**（Composite Credit Appraisal）。

### 估计财务实力（按有形净资产，美元）
| 代码 | 有形净资产区间 |
|---|---|
| 5A | 5,000 万及以上 |
| 4A | 1,000 万 – 4,999.9999 万 |
| 3A | 100 万 – 999.9999 万 |
| 2A | 75 万 – 99.9999 万 |
| 1A | 50 万 – 74.9999 万 |
| BA | 30 万 – 49.9999 万 |
| BB | 20 万 – 29.9999 万 |
| CB | 12.5 万 – 19.9999 万 |
| CC | 7.5 万 – 12.4999 万 |
| DC | 5 万 – 7.4999 万 |
| DD | 3.5 万 – 4.9999 万 |
| EE | 2 万 – 3.4999 万 |
| FF | 1 万 – 1.9999 万 |
| GG | 5,000 – 9,999 |
| HH | 5,000 以下 |

没有财报时，D&B 可能按员工人数给出「1R」（10 人及以上）或「2R」（1–9 人）这类替代评级，此时只有综合信用评估，没有财务实力。

### 综合信用评估（1–4）
| 数字 | 含义 |
|---|---|
| 1 | 高（High） |
| 2 | 良好（Good） |
| 3 | 一般（Fair） |
| 4 | 有限（Limited） |

### 特殊符号
- 「--」：没有足够信息给出评级，**不代表负面**，需要分析师自行判断。
- 「ER」：员工人数区间评级（Employee Range），常见于没有财报的小企业。
- 「DS」：信息不足以分类（Duns Support），通常只能确认企业存在。

## PAYDEX（付款指数，1–100）
按供应商反馈的付款记录计算的加权分数，**越高付款越及时**。

| PAYDEX | 付款表现 |
|---|---|
| 100 | 提前付款（Anticipate） |
| 90 | 折扣期内付款 |
| 80 | 按期付款（Prompt） |
| 70 | 平均逾期约 15 天 |
| 60 | 平均逾期约 22 天 |
| 50 | 平均逾期约 30 天 |
| 40 | 平均逾期约 60 天 |
| 30 | 平均逾期约 90 天 |
| 20 | 平均逾期约 120 天 |
| UN | 没有足够付款记录 |

- PAYDEX 反映的是**对其他供应商**的付款习惯；本公司应收账款里的付款习惯（CRA 定性项 Pay Habits）来自 SAP，两者要分开看。
- 两者差别大时值得在意见里写出来：例如对我们按期付款但对其他供应商逾期，可能说明资金紧张、在挑供应商付款。

## Failure Score（失败评分）
- 预测未来 12 个月内企业停止经营、破产或在未全额清偿的情况下关闭的可能性。
- 原始分 1001–1875，**分数越低风险越高**；同时给出 1–5 级的风险等级（1 最低风险，5 最高风险）和全国百分位（1–100，越低风险越高）。
- 演示数据里的「失败评分」用的是百分位口径（1–100）。

## Delinquency Score（逾期评分）
- 预测未来 12 个月严重逾期付款（逾期 90 天以上）的可能性，与 Failure Score 的区别是：前者看「付得晚」，后者看「倒闭」。
- 同样分 1–5 级，1 风险最低。

## 在 CRA 里怎么用
- D&B 企业信用评级是定性分里权重最大的一项（40%），演示规则按**综合信用评估数字**折算：1→1 分、2→2 分、3→4 分、4→5 分，无评级记 4 分（见《CRA 打分规则》）。
- 估计财务实力是用有形净资产划档的，可以拿来**交叉核对**：如果 D&B 是 3A（100 万–1,000 万美元），而客户财报算出的有形净资产是 5,000 万美元，要么认错了公司，要么财报口径有问题。
- 认公司（Lookup）阶段认错了 DUNS，这一项就会用别人的评级，所以 Merge 前一定要核对名称、地址和财务规模。
