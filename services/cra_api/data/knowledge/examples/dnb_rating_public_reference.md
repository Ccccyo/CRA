# D&B Rating 解释：公开资料核查卡（非客户评分）

> 类型：项目对 D&B 官方 Ratings Guide 的中文摘要；核查日：2026-10-23；适用范围：理解 D&B Rating 的组成及地域差异；状态：staging。不是任何客户的 D&B 报告、实时评分或本公司评分映射。来源：[D&B Ratings Guide](https://docs.dnb.com/reference/ratings/en-US/guide)。

## DNB-RATE-01 · 官方指南说明的结构

D&B 将 Rating 描述为多维的企业信用风险工具，由两部分组成：第一部分反映企业规模/财务实力，第二部分反映信用状况或失败可能性。第二部分在不同市场可叫 Risk Indicator、Code Condition 或 Composite Credit Appraisal，生成方法和解释也存在市场差异。因此，代码或分析师必须先确认产品、市场、报告日期及指标定义，不能把不同地域的代码直接横向比较。

## DNB-RATE-02 · CRA 场景的使用边界

一份有授权的客户 D&B 响应可作为外部风险事实或线索，但本卡不能产生客户 Rating、DUNS 号、建议额度或自动批准。若 D&B 与 SAP BP、客户财报主体不一致，应先解决实体绑定；若报告缺失、过期或字段不明，应标注未知并转人工核验。CRA 的定性档位或审批结果若要映射 D&B 值，必须有单独批准的内部规则及供应商许可，本项目目前未取得这些资料。

## DNB-RATE-03 · 获取、权限与维护

公开指南可用于术语解释；具体客户报告只能在供应商合同和案件权限允许的条件下通过正式接口/原报告获取。入库客户事实时记录产品名、市场、查询时间、版本、字段、来源 ID、访问范围和保留期限。官方指南或合同变化时重新核对；不得抓取或复刻未授权商业报告。
