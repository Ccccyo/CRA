# 测试与用户视角验收

## 1. 自动化层次

### 单元测试

- Excel 开关、BP、币种、年份和必要 Sheet 校验。
- 财务平衡、小计、数量级、历史差异和币种校验。
- 主体匹配阈值。
- 引用 ID、数字证据、选项白名单和拒答。
- 签署哈希及失效。
- Bad Case 流出层级和优先级。

### 集成测试

- Excel 导入→案件创建→文件快照。
- RAG 检索→重排→引用验证。
- Agent 步骤→人工待办→恢复。
- 内容修改→签署失效。
- 回填→重新打开→读取目标值。

### 端到端测试

1. 使用 Northstar Excel 创建案件。
2. 确认企业主体。
3. 上传或加载演示财报。
4. 处理冲突字段并签署。
5. 生成带引用的风险意见。
6. 完成定性和最终签署。
7. 导出 Excel 和审计包。
8. 重新打开 Excel 并校验回填值。

## 2. RAG 评估

- Hit@5：整体至少 90%。
- 关键规则 Top 3：100%。
- Recall@20：至少 95%。
- 数字引用一致率：100%。
- 跨案件或跨权限泄露：0。
- 无证据测试集拒答率：100%。
- 过期规则被当作当前规则：0。

现有 22 题只作回归种子，开发期扩展到至少 100 题，覆盖规则、案件、历史、公开资料、拒答、过期版本和权限隔离。

## 3. 用户视角复核

### 使用意愿

- 30 秒内能否理解工具的输入、输出和人工责任。
- 用户是否愿意上传文件，权限、保存和不直连 SAP 是否说清。
- 是否能看到 Agent 当前正在做什么。

### 使用动线

- 从 Landing 到新建案件不超过两次主操作。
- 从案件列表到当前人工待办不超过两次主操作。
- 所有阻塞状态都有可执行的解决方式。
- 浏览器刷新、返回、重复提交不会重复执行高风险动作。

### 项目逻辑

- 实际业务步骤和 Agent 步骤一一对应。
- 每个 Agent 步骤都有必要输入、明确输出和退出条件。
- RAG 只在需要知识或证据时使用，不代替校验程序。
- 人工关卡对应真实责任和风险。

### 数据准确性

- Excel 解析值与原单元格一致。
- 抽取值与原页、币种、单位和期间一致。
- 所有计算由确定性函数完成并有回归测试。
- 人工修改、派生值和模型值在 UI 中有不同标识。

### 效率

演示环境验收目标：

- 10MB 内 Excel 预检在 3 秒内返回。
- 案件列表首次可交互时间小于 2.5 秒。
- 路由切换和本地操作反馈小于 250ms。
- 长任务在 1 秒内显示已接收及当前步骤。
- Agent 运行不阻塞页面，刷新后可继续观察。

## 4. 可用性测验任务

| 任务 | 成功标准 |
|---|---|
| 创建 Northstar 案件 | 无提示帮助下完成，理解创建后会发生什么 |
| 修复一个无效年份开关 | 能定位单元格和正确值 |
| 找到 Agent 阻塞原因 | 10 秒内找到原因与需要的人工动作 |
| 核对一个财务数字 | 能打开页码、原文和修改记录 |
| 判断风险意见是否可信 | 能查看逐句引用和无证据提示 |
| 导出与验证 Excel | 文件可打开，关键单元格和命名区域保留 |
