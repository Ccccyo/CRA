# CRA Agent Workbench 业务流程

> 本文是主 PRD 的流程展开。当前事实与 P0 目标必须以 `PRODUCT.md` 和 `docs/16-capability-status.md` 为准。

## 1. 主链路

### 当前可运行链路

```text
创建案件 → Excel 校验与快照 → 企业主体候选 → 人工确认主体
→ 财报抽取与证据校验 → 人工确认财务证据
→ 授权检索与风险意见草稿 → 人工确认风险意见
→ 确定性模拟评分 → 已签财务字段、AI Import、风险意见与评分回写
→ 版本化 artifact → 额度/偏离/审批最终复核 → 完成
```

当前模拟链路已经接入 `external_score`、内容哈希签署、签署失效、vN artifact 和最终额度门禁。真实案件在没有获批评分规则时会阻断；对象存储不可变策略与生产签署表仍未完成，因此不得称为生产额度审批闭环。

### P0 目标链路

```text
创建案件
→ Excel 校验与快照
→ 企业主体候选
→ 人工确认主体
→ 财报抽取与证据校验
→ 人工签署财务证据
→ 规则、行业、国家和历史检索
→ 风险意见草稿
→ 人工确认定性判断
→ 确定性模拟评分
→ 21 个财务字段、风险意见与评分回写 Excel
→ 生成版本化 artifact 并校验
→ 额度建议与偏离说明
→ 最终人工签署
→ 导出 Excel 和审计包
```

## 2. 新建案件

### 输入

- CRA Excel `.xlsx`。
- 可选的当期财务报告 `.pdf`。
- 负责人、截止日期、案件类型。

### 自动预检

- 必要 Sheet：`Financial Statements`、`Executive Summary`、`Header params`。
- 支持的模板版本。
- BP、Credit Segment、客户、国家、币种、申请额度。
- C2:E2 年份开关。
- 当期手工年份必须位于 C 列。
- SAP 历史年份不得空值。
- 汇率和历史数据覆盖。

### 重复 BP

- 进行中案件：显示差异，由用户选择更新当前案件。
- 已完成案件：创建新评审周期，并建立历史关联。
- 系统不得静默覆盖。

### 输出

- 原文件不可变快照。
- Excel 解析结果与校验问题。
- 案件记录。
- 流程运行和首个 Agent 任务。

## 3. 案件状态

`draft` → `validating` → `ready` → `running` → `awaiting_human` → `running` → `completed`

异常分支：

- `needs_correction`：输入文件需更正。
- `blocked`：系统错误或必要数据不足。
- `cancelled`：由用户取消，保留审计信息。

## 4. 人工关卡

| 关卡 | 人工责任 | 过关条件 |
|---|---|---|
| 企业主体 | 核对名称、地址、国家、规模和标识符 | 选择候选并确认 Merge |
| 财务证据 | 核对抽取值、页码、单位和异常 | P0：无 error；warning 有接受理由；签署绑定内容版本/hash |
| 风险判断 | 确认定性项、风险意见和引用 | 所有句子有有效来源，完成签署 |
| 额度建议 | 确认方法、申请值、建议值、审批层级和偏离 | P0：非 owner 复核；偏离有说明；签署绑定 score/artifact hash `[需复核：偏离阈值与升级路径]` |

## 5. 导出

- 当前模拟导出从原快照生成 vN artifact，保存 checksum，并在新版本生成时把旧 artifact 标为 superseded；不会静默覆盖旧文件。
- 生产环境仍需将 artifact 账本迁移为规范化表，并启用对象存储不可变保留策略。
- 保留 VBA 依赖的命名区域和工作表。
- 当前当期已签财务字段写入目标区域并重开核验；真实 21 字段模板映射为 `[需复核：Excel 模板版本和目标单元格]`。
- 当前 `AI Import` 保存字段、周期、值、页码、原文、模型标识、校验提示和目标单元格；生产列定义与 Prompt 版本字段为 `[需复核：AI Import 列定义]`。
- P0 审计包保存来源、版本、签署、人工修改、Agent operation、artifact 和 Bad Case。
