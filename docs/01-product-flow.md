# CRA Agent Workbench 业务流程

## 1. 主链路

```text
创建案件
→ Excel 校验与快照
→ 企业主体候选
→ 人工确认主体
→ 财报抽取与证据校验
→ 人工签署财务证据
→ 规则、行业、国家和历史检索
→ 风险意见草稿
→ 人工确认定性判断
→ Excel 新版本回填
→ 模拟评分/等待外部评分
→ 额度建议与偏离说明
→ 最终人工签署
→ 导出 Excel 和审计包
```

## 2. 新建案件

### 输入

- CRA Excel `.xlsx`。
- 可选的当期财务报告 `.pdf`。
- 负责人、截止日期、案件类型。

### 自动预检

- 必要 Sheet：`Financial Statements`、`Executive Summary`、`Header params`。
- 支持的模板版本。
- BP、Credit Segment、客户、国家、币种、申请额度。
- C2:E2 年份开关。
- 当期手工年份必须位于 C 列。
- SAP 历史年份不得空值。
- 汇率和历史数据覆盖。

### 重复 BP

- 进行中案件：显示差异，由用户选择更新当前案件。
- 已完成案件：创建新评审周期，并建立历史关联。
- 系统不得静默覆盖。

### 输出

- 原文件不可变快照。
- Excel 解析结果与校验问题。
- 案件记录。
- 流程运行和首个 Agent 任务。

## 3. 案件状态

`draft` → `validating` → `ready` → `running` → `awaiting_human` → `running` → `completed`

异常分支：

- `needs_correction`：输入文件需更正。
- `blocked`：系统错误或必要数据不足。
- `cancelled`：由用户取消，保留审计信息。

## 4. 人工关卡

| 关卡 | 人工责任 | 过关条件 |
|---|---|---|
| 企业主体 | 核对名称、地址、国家、规模和标识符 | 选择候选并确认 Merge |
| 财务证据 | 核对抽取值、页码、单位和异常 | 无 error，修改有理由，完成签署 |
| 风险判断 | 确认定性项、风险意见和引用 | 所有句子有有效来源，完成签署 |
| 额度建议 | 确认方法、申请值、建议值和偏离 | 偏离有说明，完成最终签署 |

## 5. 导出

- 导出从原快照生成的新 Excel 版本。
- 保留 VBA 依赖的命名区域和工作表。
- 当期数据写入黄色待填区。
- `AI Import` 保存字段、周期、值、页码、原文、模型、校验和目标单元格。
- 审计包保存来源、版本、签署、人工修改、Agent 事件和 Bad Case。
