# 开发计划与门禁

## 里程碑 0：文档与基线

交付：

- PRODUCT.md 与 DESIGN.md。
- 业务流程、数据契约、Agent/RAG 设计、开发计划和测试计划。
- 原项目业务逻辑、数据和测试清单。

通过条件：

- Excel 输入输出契约前后一致。
- Agent 权限边界与人工关卡无矛盾。
- RAG 不被当作数字存储或最终决策器。
- Mock 与公开数据边界清晰。

## 里程碑 1：基础运行环境

- 将 ShipAny 文案、导航和元数据更换为 CRA 产品。
- 建立 Python CRA Service 与健康检查。
- 建立本地 SQLite、文件库和种子数据。
- 提供单一本地启动命令和环境变量校验。

门禁：前后端健康检查通过，无密钥泄露，可读取种子案件。

## 里程碑 2：新建案件与 Excel

- 上传、解析、校验和预览 CRA Excel。
- 同 BP 差异与评审周期处理。
- 创建案件、文件快照和首个 Agent 运行。
- 上传失败、拖拽、大文件和校验错误状态。

门禁：Northstar 样例可创建案件；无效工作簿被拦截；原文件不被覆盖。

## 里程碑 3：案件工作台

- 案件列表与待办排序。
- 案件三列工作台。
- Agent 当前任务、步骤计数、工具、校验和事件流。
- 人工待办、证据查看和返回修改。

门禁：刷新后进度不丢失；案件可直链；移动端可完成必要操作。

## 里程碑 4：RAG

- 迁移现有分块、BM25、向量、RRF、重排和评估。
- 建立四个 Namespace 和元数据过滤。
- 建立案件问答、风险起草证据包和引用校验。
- 建立公开数据适配器与来源更新记录。

门禁：关键规则 Top 3 命中 100%；跨案件泄露 0；无证据问题正确拒答。

## 里程碑 5：Agent 完整链路

- 状态机、幂等步骤、有限重试和人工关卡。
- 主体候选、财务抽取/校验、风险起草、Excel 回填和模拟评分。
- 签署哈希和上游更改失效。
- Bad Case 记录与回归集入库。

门禁：端到端样例从上传到导出完成；Agent 在人工关卡停止；改动已签内容会失效签署。

## 里程碑 6：Landing 与最终硬化

- 完成 Landing 和应用内视觉系统。
- 删除主导航中的价格、博客、案例、生成器和积分功能。
- 错误、空状态、加载、权限、响应式和无障碍硬化。
- 构建、lint、自动化测试和视觉复核。

门禁：无无关入口；无伪造客户或指标；桌面和移动视图通过复核。
