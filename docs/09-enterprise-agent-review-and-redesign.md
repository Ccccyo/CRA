# CRA Agent Workbench 企业 Agent 审查结论（已整合）

> 原审查内容已在 2026-11-03 整合进 `PRODUCT.md` 和 `docs/16-capability-status.md`。为避免旧测试数量、运行状态和能力结论继续被引用，本文不再保留旧版本描述。

## 1. 当前有效结论

CRA Agent Workbench 是一个可运行的企业信用评审验证型原型。它已经具备 Excel 交接、主体候选、财报抽取/校验、受控工作流、人工任务、RAG/引用校验、风险草稿、模拟评分、完整回写、hash 签署、最终门禁和 Bad Case 等能力；生产迁移与真实业务规则仍未完成。

当前对外口径必须同时满足：

- 不把 Mock SAP/D&B/SCASE 描述为真实生产集成；
- `external_score` 仅可描述为模拟主流程能力，不得描述为真实评分服务；
- hash 签署当前是案件 notes 中的最小实现，不得描述为已完成独立生产签署表迁移；
- vN + checksum 是当前 artifact 账本，不得描述为已启用对象存储不可变保留策略；
- 不把配置默认开启描述为向量/重排已在线，运行状态以 `/health.rag` 为准；
- 不引用旧版固定测试数量或“22/22、100%”作为当前质量结论；
- 不宣称已经获得真实业务效率、采纳、坏账或收入改善。

## 2. P0 改造范围

1. P0-A：运行事实清单、版本追溯和发布证据；
2. P0-B：operation/step、hash-bound signoff 与 artifact 账本；
3. P0-C：财务门禁、确定性模拟评分、完整 Excel 回写、版本化交付和独立最终复核；
4. P0-D：输入边界、提示注入、权限、日志最小化和文件生命周期；
5. P0-E：规则/契约/RAG/E2E/用户走查的分层评测与发布门禁。

完整需求、异常、待确认项与验收矩阵见 `PRODUCT.md`；当前证据和未完成项见 `docs/16-capability-status.md`。
